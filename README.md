# local-keiba-analyzer

NAR地方競馬向けの予想・分析Webアプリ（v0.3）。
競馬場とレース番号を選ぶと、各出走馬の **予想指数・予測勝率・単勝オッズ・期待値・印・評価理由** を比較できます。
「一番勝ちそうな馬（本命）」と「オッズまで考えると買う価値が高い馬（単勝候補・穴馬）」を分けて表示します。

> **公開版はモックデータ（架空の馬・騎手）で動作します。** 実在のレースとは関係ありません。
> NAR 実データは Basic 認証付きの本人専用モード（`/real/`）でのみ表示します。
> 本アプリは予想の参考情報であり、的中や利益を保証するものではありません。

## 使い方

```bash
npm install
npm start          # http://localhost:3000 （PORT 環境変数で変更可）
npm test           # 自動テスト（node:test）
```

スマートフォンのブラウザ向けに最適化しています（PCはレスポンシブで2カラム表示）。
URL の `#ooi-5` のようなハッシュで、競馬場とレースを指定して共有できます。

## 予想ロジック（v0.1：ルールベース）

1. **ファクタースコア（0〜1）**
   | 項目 | ウェイト | 内容 |
   | --- | --- | --- |
   | 近走成績 | 35% | 直近5走の着順・着差を直近ほど重く（35/25/18/12/10%） |
   | 距離適性 | 20% | 同距離成績（勝利=1、2-3着=0.5）を事前分布で平滑化 |
   | 競馬場適性 | 15% | 当地成績70% + 馬場適性30% |
   | 騎手評価 | 10% | 騎手評価 / 100 |
   | 斤量 | 10% | 出走馬平均との差 + 前走からの増減 |
   | クラス/休養 | 10% | クラス評価60% + 休養日数40% |
2. **予想指数（0〜100）**: 利用可能な項目だけでウェイトを再正規化。データのカバー率が低い馬は平均（50）寄りに補正。
3. **予測勝率**: softmax（温度7）。1頭が60%を超える場合は温度を上げて平準化し、一様分布を2%ブレンド。合計は100%。
4. **期待値** = 予測勝率 × 単勝オッズ（オッズが null / 0 / 未取得なら「オッズ未取得」）
   - 1.20以上 高期待値 / 1.00〜1.19 妙味あり / 0.80〜0.99 やや割高 / 0.80未満 妙味低い
5. **印**: 予測勝率上位から ◎○▲。☆は残りから「4番人気以下・期待値1.0以上・勝率3%以上」で期待値最大の馬。△は残りの上位2頭。
6. **レース結論**
   - 危険な人気馬: 3番人気以内で期待値0.8未満（◎を除く）
   - 単勝候補: 期待値1.0以上かつ予測勝率5%以上（最大3頭）
   - 馬連候補: ◎-○、◎-▲、◎-☆ などから3組
   - 見送り: 期待値1.0以上の馬がいない／上位3頭の指数差が4未満／欠損データが多い

## データ形式（アダプターが返す馬データ）

```js
{
  number, frame, name, jockey,
  weight, lastWeight,                       // 斤量（今回・前走）
  odds,                                      // 単勝オッズ（null可）
  recentFinishes: [1, 3, ...],               // 直近5走の着順（左が前走）
  recentMargins: [-0.2, 0.5, ...],           // 着差（秒、勝ち馬はマイナス）
  sameDistanceRecord: { starts, wins, places },
  trackRecord: { starts, wins, places },
  surfaceAptitude,                           // 馬場適性 1〜5
  jockeyRating, classRating,                 // 0〜100
  restDays
}
```

すべての項目は null / 欠損でも動作します（NaN・Infinity は出力しません）。

## 本人専用モード（v0.2：NAR 実データ）

公開版（`/`）はモックデータのままです。`/real/` を開くと、Basic 認証のうえで NAR 実データを使う本人専用モードになります。

- **データ元**: 地方競馬情報サイトの公式データダウンロード機能（当日ファイル `race.zip` / `odds.zip`）。仕様は [データダウンロード機能説明書](https://www.keiba.go.jp/pdf/manual/data_pdf_manual.pdf)。
- **取得頻度**: アクセスがあったときだけ取得し、サーバー側で **5分キャッシュ**（公式推奨の上限は当日ファイル2分に1回）。同時アクセスは1回の取得にまとめ、失敗後2分間は再取得しません。月次ファイルは今日の出走馬の近5走を作るためだけに使います（下記「近5走」）。
- **フォールバック**: `race.zip` の取得・展開・解析に失敗したらモックを表示し、画面上部に理由を表示します。`odds.zip` だけ失敗した場合はオッズ無しの実データを表示します。
- **表示**: ヘッダーのバッジで「実データ」（黄）/「モック」（失敗時は赤）を明示します。
- **公開範囲**: NAR の利用規約（転載・複製の禁止、FAQ「レース情報の商用利用および改変しての転載を禁じます」）を踏まえ、本人限定です。NAR への確認が取れるまで一般公開しません。NAR のデータはリポジトリに保存しません（テストは架空データ）。

| 環境変数 | 内容 |
| --- | --- |
| `REAL_AUTH_USER` | 本人専用モードのユーザー名 |
| `REAL_AUTH_PASSWORD` | 同パスワード（Render ダッシュボードで設定。Git に保存しない） |

両方が未設定なら `/real/` は無効（503）になります。

| メソッド | パス | 説明 |
| --- | --- | --- |
| GET | `/real/` | 本人専用モードの画面 |
| GET | `/real/api/tracks` ・ `races` ・ `race` | 公開版 API と同じ形式（`dataStatus` で実データ/モックを返す） |
| GET | `/real/api/diag` | NAR 疎通診断（当日 race.zip を1回取得。2分に1回まで） |

### 近5走（v0.3：月次ファイル）

今日の出走馬について、月次ファイル（レース情報、当月を含む過去6か月分）から**馬名＋生年月日**で過去走を照合し、直近5走を取得します（公式に馬を一意に特定するIDは提供されていません）。取得する項目は、着順・頭数・着差（勝ち馬とのタイム差も計算）・距離・競馬場・馬場状態・走破タイム・上がり3F・前走からの日数です。表示対象は今日のレースだけです。過去レースの閲覧・バックテスト・予想履歴の保存は行いません。

- **保存**: 月ごとに必要な項目だけを gzip して Render Key Value（無料・内部接続のみ、`REDIS_URL`）に保存します。Web サービスがスリープしても再取得しません。Key Value が無い環境（ローカル）ではメモリに保持します。
- **取得頻度**: 同じ月を取りに行くのは **1日1回まで**（03:00 JST を境界とし、公式の更新は午前2時頃）。確定済みの月（翌月2日 03:00 JST 以降に取得したもの）は再取得しません。失敗時は保存済みデータを使い、1時間は再試行しません。月をまたいで取得するときは1秒間隔を空けます。
- **照合できない馬**: 近6か月に NAR での出走が無い馬（長期休養明け・中央などからの転入・新馬）は、近走・休養を評価せず、残りの項目で評価します。
- 月次データが使えないときは、近走無しで v0.2.1 と同じ項目で予想し、画面に警告を出します。

### 実データ用の予想プロファイル（v0.3：`narDaily`）

当日ファイルには近走着順・騎手評価・休養日数が無いため、実データは専用のプロファイル（`src/prediction/profiles/narDaily.js`）で予想します。モック用の予想ロジック（`default`）は v0.1 のままです。

| ファクター | ウェイト | 正規化 |
| --- | --- | --- |
| 近走成績 | 30% | 近5走を直近ほど重く（35/25/18/12/10%）。1走 = 0.65×着順（頭数に対する相対位置）+ 0.35×勝ち馬とのタイム差（1400m換算）。走数が少ないほど平均的な馬へ寄せる |
| 全成績 | 15% | 能力水準 L：着順ポイント（1着1・2着0.5・3着0.3）の率を全体平均0.18へ仮想6戦分寄せる |
| 当競馬場成績 | 10% | L + 当地適性（当地の率 − 他場の率）。差に両方の出走数の信頼度 n/(n+8) を掛ける |
| 当距離成績 | 15% | L + 当地適性 + 距離適性（当コース当距離の率 − 当地他距離の率、信頼度 n/(n+6)） |
| 持ち時計 | 15% | 出走馬の中央値との差（秒）をロジスティックで0〜1に。当距離の出走数が少ないほど0.5へ寄せる |
| 斤量 | 5% | 出走馬平均より1kg重いごとに-0.05 |
| 馬体重増減 | 5% | 増減0が最良。±12kgで0.37 |
| 休養 | 5% | 前走からの日数（10〜60日が最良） |

- 暫定案（持ち時計15%・斤量10%）から、持ち時計を20%・斤量を5%に変更しました。成績系は相手関係（クラス）を反映しないので、出走馬間で直接比較できる時計の比重を上げています。また NAR の斤量差は性別・年齢・減量騎手・ハンデなど能力差を埋めるためのものなので、比重を下げています。
- 成績系3項目はポイント率で推定し、1-exp(-率/0.3) で0〜1にします（上限で頭打ちにしない）。全成績 ⊇ 当競馬場 ⊇ 当距離 の入れ子なので、当地・当距離は別の水準としては扱いません。「全成績の水準 + その条件での適性」として推定するので、少数サンプルの補正による見かけの差も出ません。適性は出走数が少ないほど0に近づき（当地1戦2着で+3点程度）、比較相手が無い（当地しか走っていない）場合は0です。
- 欠損項目は残りのウェイトで再正規化します。持ち時計は、距離に対して非現実的な値（12.5〜18.5m/秒の範囲外）なら使いません。
- **単勝オッズは予想指数・予測勝率に使いません。** 期待値・人気・☆の段階でだけ使います。
- 予測勝率は softmax の温度7です。1番手の平均勝率は0.34で、市場の1番人気（0.41）より控えめです。
- 単勝候補の条件は、期待値1.0以上・予測勝率8%以上・**予測勝率が市場勝率の2倍以内**です。大きな乖離は、当日データに無い情報（クラス・近走・調子）による見落としの可能性が高いためです。

**見送り**は買う根拠が無いときだけです。対象は、オッズ未発表／期待値1.0以上の候補なし／1番手の勝率が均等割の1.25倍未満、または上位3頭の指数差が2未満（横一線）／評価可能なデータ（利用率30%以上）を持つ馬が半数未満、のいずれかです。

**予想信頼度（高/中/低）**は見送りとは独立です。平均データ利用率・成績サンプル（通算5戦以上の馬の割合、当距離実績のある馬の割合）・上位3頭の指数差をそれぞれ0〜2点で評価します。

ウェイトと閾値は 2026-10-06 の実データで分布を確認した暫定値です。バックテスト（月次ファイル）での再較正が必要です。

出走取消・競走除外の馬（着差欄に表記）は除外します。発売前のオッズ（0.0）は未取得として扱います。
