# local-keiba-analyzer

NAR地方競馬向けの予想・分析Webアプリ（v0.2）。
競馬場とレース番号を選ぶと、各出走馬の **予想指数・予測勝率・単勝オッズ・期待値・印・評価理由** を比較できます。
「一番勝ちそうな馬（本命）」と「オッズまで考えると買う価値が高い馬（単勝候補・穴馬）」を分けて表示します。

> **公開版はモックデータ（架空の馬・騎手）で動作します。** 実在のレースとは関係ありません。
> NAR 実データは Basic 認証付きの本人専用モード（`/real/`）でのみ表示します。
> 本アプリは予想の参考情報であり、的中や利益を保証するものではありません。

## 使い方

```bash
npm install
npm start          # http://localhost:3000 （PORT 環境変数で変更可）
npm test           # 自動テスト（node:test）
```

スマートフォンのブラウザ向けに最適化しています（PCはレスポンシブで2カラム表示）。
URL の `#ooi-5` のようなハッシュで、競馬場とレースを指定して共有できます。

## 予想ロジック（v0.1：ルールベース）

1. **ファクタースコア（0〜1）**
   | 項目 | ウェイト | 内容 |
   | --- | --- | --- |
   | 近走成績 | 35% | 直近5走の着順・着差を直近ほど重く（35/25/18/12/10%） |
   | 距離適性 | 20% | 同距離成績（勝利=1、2-3着=0.5）を事前分布で平滑化 |
   | 競馬場適性 | 15% | 当地成績70% + 馬場適性30% |
   | 騎手評価 | 10% | 騎手評価 / 100 |
   | 斤量 | 10% | 出走馬平均との差 + 前走からの増減 |
   | クラス/休養 | 10% | クラス評価60% + 休養日数40% |
2. **予想指数（0〜100）**: 利用可能な項目だけでウェイトを再正規化。データのカバー率が低い馬は平均（50）寄りに補正。
3. **予測勝率**: softmax（温度7）。1頭が60%を超える場合は温度を上げて平準化し、一様分布を2%ブレンド。合計は100%。
4. **期待値** = 予測勝率 × 単勝オッズ（オッズが null / 0 / 未取得なら「オッズ未取得」）
   - 1.20以上 高期待値 / 1.00〜1.19 妙味あり / 0.80〜0.99 やや割高 / 0.80未満 妙味低い
5. **印**: 予測勝率上位から ◎○▲。☆は残りから「4番人気以下・期待値1.0以上・勝率3%以上」で期待値最大の馬。△は残りの上位2頭。
6. **レース結論**
   - 危険な人気馬: 3番人気以内で期待値0.8未満（◎を除く）
   - 単勝候補: 期待値1.0以上かつ予測勝率5%以上（最大3頭）
   - 馬連候補: ◎-○、◎-▲、◎-☆ などから3組
   - 見送り: 期待値1.0以上の馬がいない／上位3頭の指数差が4未満／欠損データが多い

## データ形式（アダプターが返す馬データ）

```js
{
  number, frame, name, jockey,
  weight, lastWeight,                       // 斤量（今回・前走）
  odds,                                      // 単勝オッズ（null可）
  recentFinishes: [1, 3, ...],               // 直近5走の着順（左が前走）
  recentMargins: [-0.2, 0.5, ...],           // 着差（秒、勝ち馬はマイナス）
  sameDistanceRecord: { starts, wins, places },
  trackRecord: { starts, wins, places },
  surfaceAptitude,                           // 馬場適性 1〜5
  jockeyRating, classRating,                 // 0〜100
  restDays
}
```

すべての項目は null / 欠損でも動作します（NaN・Infinity は出力しません）。

## 本人専用モード（v0.2：NAR 実データ）

公開版（`/`）はモックデータのままです。`/real/` を開くと、Basic 認証のうえで NAR 実データを使う本人専用モードになります。

- **データ元**: 地方競馬情報サイトの公式データダウンロード機能（当日ファイル `race.zip` / `odds.zip`）。仕様は [データダウンロード機能説明書](https://www.keiba.go.jp/pdf/manual/data_pdf_manual.pdf)。
- **取得頻度**: アクセスがあったときだけ取得し、サーバー側で **5分キャッシュ**（公式推奨の上限は当日ファイル2分に1回）。同時アクセスは1回の取得にまとめ、失敗後2分間は再取得しません。月次ファイルは未使用です（使う場合も1日1回以下）。
- **フォールバック**: `race.zip` の取得・展開・解析に失敗したらモックを表示し、画面上部に理由を表示します。`odds.zip` だけ失敗した場合はオッズ無しの実データを表示します。
- **表示**: ヘッダーのバッジで「実データ」（黄）/「モック」（失敗時は赤）を明示します。
- **公開範囲**: NAR の利用規約（転載・複製の禁止、FAQ「レース情報の商用利用および改変しての転載を禁じます」）を踏まえ、本人限定です。NAR への確認が取れるまで一般公開しません。NAR のデータはリポジトリに保存しません（テストは架空データ）。

| 環境変数 | 内容 |
| --- | --- |
| `REAL_AUTH_USER` | 本人専用モードのユーザー名 |
| `REAL_AUTH_PASSWORD` | 同パスワード（Render ダッシュボードで設定。Git に保存しない） |

両方が未設定なら `/real/` は無効（503）になります。

| メソッド | パス | 説明 |
| --- | --- | --- |
| GET | `/real/` | 本人専用モードの画面 |
| GET | `/real/api/tracks` ・ `races` ・ `race` | 公開版 API と同じ形式（`dataStatus` で実データ/モックを返す） |
| GET | `/real/api/diag` | NAR 疎通診断（当日 race.zip を1回取得。2分に1回まで） |

### 実データで使える項目（v0.2 時点）

| 予想ファクター | 実データでの扱い |
| --- | --- |
| 近走成績 | **無し**（当日ファイルに近走着順が含まれない） |
| 距離適性 | 「うち当距離成績」（当競馬場・当距離） |
| 競馬場適性 | 「当競馬場成績」+ 今回の回りのダート左/右成績を馬場適性(1〜5)に換算 |
| 騎手評価 | **無し**（「騎手成績」の集計範囲が仕様書に記載されていないため未使用） |
| 斤量 | 「負担重量」（★☆▲◇ の減量記号は除去）。前走斤量は無し |
| クラス/休養 | **無し** |
| 単勝オッズ | odds.csv の単勝（発売前は 0.0 → オッズ未取得扱い） |

出走取消・競走除外の馬（着差欄に表記）は除外します。データのカバー率が低いため、現状は多くのレースが「欠損データが多い」で見送り判定になります。
